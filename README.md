# 🛒 বাজার দর | BazarDor

### Essential Product Prices at a Glance

**BazarDor** is a Next.js-based web application that helps users explore the prices of essential products in one place. It provides a convenient way to browse products, compare market prices, track price changes, and stay informed about everyday necessities.

---

## ✨ Key Features

1. **📊 Product Price Tracking** — View current prices and compare them with previous prices to understand market trends.

2. **🏪 Market Price Comparison** — Explore available market prices to compare the minimum and maximum prices of products.

3. **🔎 Product Browsing by Category** — Browse essential products by category and find relevant items easily.

4. **🔐 Secure Authentication** — Register and sign in using email and password, or authenticate through Google and GitHub with Better Auth.

5. **📱 Responsive User Interface** — Enjoy a clean, user-friendly experience across desktop, tablet, and mobile devices.

---

## 🛠️ Technologies Used

- **Next.js** — React framework for web application development
- **React** — Component-based user interface
- **TypeScript** — Type-safe JavaScript development
- **Tailwind CSS / CSS** — Styling and responsive layouts
- **Better Auth** — Authentication and social login
- **REST API** — Product and market price data integration
- **Git & GitHub** — Version control and source code management

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Rawayan/Bazar-Dor-Next.js-project.git
```

### 2. Navigate to the Project Directory

```bash
cd Bazar-Dor-Next.js-project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the project root and configure the required environment variables.

Use `.env.example` as a reference for the required variable names. Add your own credentials for Better Auth, Google OAuth, and GitHub OAuth.

**Important:** Never commit `.env.local` or expose your secret credentials in a public repository.

### 5. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🔑 Authentication

BazarDor supports:

- Email and password registration
- Email and password sign-in
- Google social authentication
- GitHub social authentication
- Login and registration feedback through toast notifications

Google and GitHub authentication require valid OAuth credentials and correctly configured callback URLs.
